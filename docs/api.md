# API contract

Base URL: same origin as the site (`http://localhost:8080` locally).
All responses are JSON. There is no login for the public API by design.

## Cards (Feature 1)

### `POST /api/cards/`

Create a card. `multipart/form-data` (needed for a photo) or JSON.

Header: `X-Session-Token: <16-128 chars>` (random value generated by the
browser and kept in `localStorage`; used only for the rate limit).

| Field | Type | Rule |
|---|---|---|
| `text` | string | 1 to 280 characters after trimming |
| `x`, `y` | number | Position on the canvas, -50,000 to 50,000 |
| `image` | file, optional | JPEG or PNG, at most 5 MB. Re-encoded, metadata removed |
| `tz_offset` | int, optional | Reader's minutes east of UTC, links the card to tonight's prompt internally |

| Status | Body | Meaning |
|---|---|---|
| 201 | `{"status":"published","card":Card}` | Passed screening, now live |
| 202 | `{"status":"withheld","detail":str,"resources":[Resource]}` | Crisis indicator. Not published; show the resources |
| 422 | `{"status":"rejected","detail":str}` | Threat, harassment, personal information or link |
| 429 | `{"status":"rate_limited","detail":str}` | More than 5 posts in the last hour for this session |
| 400 | field errors | Validation failed or token missing |

### `GET /api/cards/`

Latest 200 published cards, newest first (no bounding box).

### `POST /api/cards/<id>/report/` (Feature 5)

Body (optional): `{"reason": "harmful" | "personal_info" | "spam" | "worried" | "other"}`.
Returns 201. No account, no reporter identity stored. Three open reports, or a
single `worried` report, move the card to the review queue and hide it for
everyone.

## Feed (default view)

### `GET /api/cards/feed/?seed=<random per visit>&offset=0&limit=40`

All published cards in a stable shuffle keyed by `seed` (same visit, same
order; new visit, new order), paged for infinite scroll. `limit` max 100.
No ranking of any kind.

```json
{ "cards": [Card, ...], "next_offset": 40 }
```

`next_offset` is `null` on the last page.

## Canvas (Feature 2)

### `GET /api/canvas/viewport/?min_x=&min_y=&max_x=&max_y=[&limit=]`

Published cards inside the rectangle, newest first, at most 200.

```json
{ "bbox": {"min_x": -600, "min_y": -400, "max_x": 600, "max_y": 400},
  "cards": [Card, ...] }
```

## Nightly prompt (Feature 3)

### `GET /api/prompt/current/?tz_offset=<minutes east of UTC>`

```json
{ "id": 12, "text": "What are you holding on to?", "night_of": "2026-11-01", "in_window": true }
```

`in_window` is true between 21:00 and 05:00 in the reader's time zone. Outside
the window the previous night's prompt is returned with `in_window: false`.

## Moderation (Feature 5)

* `GET /api/moderation/resources/` returns `{"resources": [Resource]}`
* `GET /api/moderation/report-reasons/` returns the report reasons and labels
* `/admin/` hosts the manual review queue (team accounts only)

## Live delivery (Feature 4)

`ws://<host>/ws/canvas/` (or `wss://` behind HTTPS)

| Direction | Message |
|---|---|
| client to server | `{"type":"viewport","min_x":..,"min_y":..,"max_x":..,"max_y":..}` on connect and after each pan or zoom |
| client to server | `{"type":"ping"}` every 25 s |
| server to client | `{"type":"subscribed","groups":n}` |
| server to client | `{"type":"card.created","card":Card}` |
| server to client | `{"type":"card.hidden","id":"<uuid>"}` when moderation removes a card |
| server to client | `{"type":"pong"}` |

## Shapes

```ts
type Card = { id: string; text: string; image: string | null; x: number; y: number; created_at: string };
type Resource = { region: string; name: string; detail: string; url: string | null };
```

A `Card` never carries an author, session, IP or prompt reference.

## Health

`GET /api/health/` returns `{"status":"ok"}` when the database answers.
